This is A Banking System.
Author: VaradNVS

Features:
- DEPOSIT
- WITHDRAW
- CHECK BALANCE
- CHECK TRANSACTION
- SAVE/LOAD USER AND ITS HISTORY
- CHECK LOGS AND SAVED IN LOGS FILE WITH DATE AND TIME
_______________________________________________________
TO RUN THE SYSTEM ->
cd to file location mainly through MSYS2 MINGW64
command to create o and executable file.

-> make debug

and then to run the program

-> make execute

and voila. you have a running bank system program.
